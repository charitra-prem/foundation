Implemented Clerk OAuth (Google + email) authentication for the Expo Router app. Added `@clerk/expo@^3.4.3` and `expo-secure-store@~56.0.4` as dependencies. The root `_layout.tsx` now wraps the entire app in `ClerkProvider` (using the built-in `tokenCache` backed by `expo-secure-store`) and includes an `InitialLayout` component that checks `useAuth` to redirect unauthenticated users to `/(auth)/sign-in` and authenticated users away from the auth group to `/(tabs)`. The sign-in screen supports email/password auth via `useSignIn` and Google SSO via `useSSO` with `strategy: 'oauth_google'`. The sign-up screen supports the same two paths and includes a two-step email verification flow (collect credentials → show code input after `prepareEmailAddressVerification`). A `.env.example` file documents the required `EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY` env var. Tests were updated with Clerk mock stubs and 2 new assertions verifying the Google OAuth button renders on both auth screens; all 7 tests pass.
