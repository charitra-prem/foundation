Added PostHog analytics to the Expo app (AIO-17). Installed `posthog-react-native` along with its Expo peer dependencies (`expo-file-system`, `expo-application`, `expo-device`, `expo-localization`). Updated `src/app/_layout.tsx` to wrap the app in `PostHogProvider` (keyed off `EXPO_PUBLIC_POSTHOG_API_KEY` / `EXPO_PUBLIC_POSTHOG_HOST` env vars, disabled automatically when the key is absent) and added a `ScreenTracker` component that calls `posthog.screen()` on every route change via `usePathname` + `useGlobalSearchParams`. Created `.env.example` to document the required variables. Added `src/app/__tests__/analytics.test.tsx` with two tests verifying the root layout renders without error and that `posthog.screen` is called on mount; all 7 tests (existing + new) pass.
