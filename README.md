# foundation

Production-ready RN/Expo base. The pipeline ships features here as Linear issues land.

## Stack
- **Routing**: expo-router (file-based)
- **Auth**: @clerk/clerk-expo (OAuth + email)
- **OTA**: expo-updates + EAS
- **Analytics**: posthog-react-native
- **Errors**: @sentry/react-native
- **Editor**: TipTap-in-WebView (via react-native-webview)

## Run
```
npm install
npx expo start
```
